How skill and decision-making apply

ShreeWin includes different game formats rather than one single type of skill game. Reading rules, watching the countdown, checking the selected period and reviewing a choice before confirmation all require attention and responsible decision-making.

These actions can help you avoid input mistakes, but they cannot guarantee a result. Lottery, colour, number and crash-style formats may include chance or system-generated outcomes, so check the Rules section for the exact game you open.

WinGo is a colour and number game available in the ShreeWin app. Before you join a round, check the selected period, available choices, countdown and result history shown on the game screen.

04

Check the selected period, available choices, entry amount and result rules inside the game before you continue.

07

Common game-screen terms

Period or round identifies one game cycle. Countdown shows how much time remains before that cycle closes. Result History lists completed periods, while Transaction or Game History shows the record connected with your account.

Use the period number to match a result with the correct entry. The same game name can have different periods or entry options, so read the labels on the active screen instead of relying on an older screenshot.

  • Period or round number
  • Countdown and closing time
  • Selected choice
  • Entry amount
  • Result History
  • Account transaction record
08

What to check on every game screen

Check the selected game name, round period, countdown, available choices, entry amount and result history before you tap Confirm. Make sure the round is still open and review any rule that affects settlement.

Use a fixed time and spending limit for paid play. Users must be 18+ and should check the laws that apply in their state or location.

  • Game name and selected period
  • Round countdown
  • Available choices
  • Entry amount
  • Result and transaction record
  • Current game rules
